Problématique et Livrables du Projet
Problématique Centrale : 
Comment créer un LLM conversationnel qui, en dialogue interactif, utilise un contexte dynamique pour converger vers une décision de fraude ?

Livrables Réalisés : 
Code chatbot complet (Python + LLM API)
30 transcriptions de dialogues (évaluations massives)
Métriques de performance (Précision, Recall, Convergence)
